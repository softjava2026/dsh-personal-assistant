# 个人智慧助手 Skill

本 skill 是"个人智慧助手"的**编排层**：它不重新实现各能力，而是判断用户意图、路由到正确的底层能力（记忆 / 日程 / 待办 / 笔记），并负责跨能力编排与安全确认。

## 核心原则

1. **路由，不重复造**：记忆走 `openviking-memory`，日程/待办/提醒走 `dingtalk-*`，笔记走本 skill 的 `pa` 工具。
2. **跨能力编排**：一句话可能命中多能力（例："记一下明天和产品部开会" = 建日程 + 建提醒），要拆解后按依赖顺序执行。
3. **写操作先确认**：任何会对外产生效果的动作（发消息/改日程/删笔记）先向用户确认。

## 能力路由表

| 用户意图 | 路由 | 说明 |
|---|---|---|
| 记住某事 / 回顾记忆 / "我之前说过" | `openviking-memory` | 语义检索 + 自动记忆 |
| 查日程 / 建日程 / 改期 / 取消 / 会议 | `dingtalk-calendar` | `dws calendar ...` |
| 建待办 / 查待办 / 逾期 / 标记完成 | `dingtalk-todo` | `dws todo ...` |
| 提醒（时间/循环） | `dingtalk-calendar` 或 `dingtalk-todo` | 按触发方式选择 |
| 记笔记 / 速记 / 查笔记 | 本 skill 的 `pa` 工具 | M1 就绪（本地 SQLite） |
| 信息检索 / 摘要 | 联网搜索 + 本 skill 编排 | 结合记忆做个性化 |

> 具体命令与参数以对应 skill 的 reference 为准；本 skill 只做路由与编排，不复制命令细节。

## 主动智能（Proactive）✅ M1 已生效

本 bundle 在 `agent/pre-step` 注入**每日摘要**（今日日程 / 逾期待办 / 最近笔记），**每个会话每天只注入一次**。当用户问"今天有什么安排"时，优先从已注入的上下文中回答，而不是重新逐项查询；摘要缺失时再按路由表实时查询。

## 笔记工具面（MCP）

本 bundle 自带的笔记后端，工具名前缀 `mcp__pa__`：

| 工具 | 用途 |
|---|---|
| `pa__note_create` | 记一条笔记（可带标签）|
| `pa__note_search` | 按关键词检索笔记（正文 + 标签）|
| `pa__note_list` | 列出最近笔记 |
| `pa__note_delete` | 删除笔记 —— **写操作，必须先确认** |

数据落在 `~/.dsh/storages/pa-notes.sqlite`（纯本地，不出网）。

## 安全契约

详见 [references/safety.md](references/safety.md)。要点：
- 写操作（发消息/改日程/删笔记/下单）**必须**先确认，确认后执行。
- 不编造 ID、不猜参数，一律从命令返回或记忆检索中取。
- 危险操作（删除、对外发送）需用户明确同意。
